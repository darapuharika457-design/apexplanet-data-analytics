# ApexPlanet Data Analytics Internship

This repository contains all the tasks completed during the ApexPlanet Data Analytics Internship. The internship focuses on Python, SQL, Data Visualization, and Business Intelligence using Power BI.

---

## Task 1: Data Loading and Exploratory Data Analysis (EDA)

### Activities Performed
- Loaded and explored the Sample Superstore dataset using Pandas.
- Performed data cleaning and preprocessing.
- Handled missing values and removed duplicate records.
- Detected and analyzed outliers.
- Conducted exploratory data analysis (EDA).
- Created visualizations using Matplotlib and Seaborn.
- Generated business insights from sales, profit, discount, and regional performance.

### Key Skills
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Data Cleaning
- Exploratory Data Analysis (EDA)
