# ApexPlanet Data Analytics Internship

This repository contains all the tasks completed during my **Data Analytics Internship at ApexPlanet Software Pvt. Ltd.**

The internship focuses on **Python, SQL, Data Visualization, Statistical Analysis, Machine Learning, and Business Intelligence** using the **Sample Superstore Dataset**.

---

#  Task 1: Data Loading and Exploratory Data Analysis (EDA)

## Activities Performed

- Loaded the Sample Superstore dataset using Pandas.
- Performed data cleaning and preprocessing.
- Handled missing values and removed duplicate records.
- Detected and analyzed outliers.
- Conducted Exploratory Data Analysis (EDA).
- Created visualizations using Matplotlib and Seaborn.
- Generated business insights from Sales, Profit, Discount, and Regional performance.

#  Task 4: Advanced Analytics & Statistical Modeling

## Activities Performed

### Statistical Analysis

- Calculated descriptive statistics:
  - Mean
  - Median
  - Mode
  - Standard Deviation
  - Skewness
  - Kurtosis
- Performed Hypothesis Testing:
  - Independent t-test
  - Chi-Square Test
- Calculated Confidence Intervals.
- Documented statistical findings with business insights.

### Time Series Analysis

- Converted the Order Date column into datetime format.
- Created monthly sales trends.
- Resampled sales data.
- Performed trend analysis.
- Built a simple Moving Average Forecast.

### Customer Segmentation

- Selected numerical features for clustering.
- Standardized data using StandardScaler.
- Applied K-Means Clustering.
- Determined the optimal number of clusters using the Elbow Method.
- Reduced dimensions using PCA.
- Visualized customer clusters.
- Profiled customer segments with business recommendations.

### Predictive Modeling

- Built a Linear Regression model to predict Profit.
- Split data into training and testing datasets.
- Evaluated the model using:
  - R² Score
  - Mean Absolute Error (MAE)
  - Root Mean Squared Error (RMSE)
- Identified the most influential features affecting Profit.
- Visualized feature importance.

## Key Skills

- Statistics
- Hypothesis Testing
- Confidence Intervals
- Time Series Analysis
- Machine Learning
- K-Means Clustering
- PCA
- Linear Regression
- Model Evaluation
- Scikit-learn
