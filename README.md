# ApexPlanet Data Analytics Internship

## Project Overview

This project was completed as part of the **ApexPlanet Data Analytics Internship**. The objective was to perform end-to-end data analysis on the Sample Superstore dataset and generate meaningful business insights through visualization, statistical analysis, customer segmentation, and predictive modeling.

---

## Project Objectives

* Perform data cleaning and preprocessing
* Conduct Exploratory Data Analysis (EDA)
* Build interactive Power BI dashboards
* Analyze business performance using SQL and Python
* Perform customer segmentation using K-Means Clustering
* Build a Linear Regression model for profit prediction
* Automate the data processing pipeline

## Dataset

---

## Key Business Insights

* Technology category generated the highest sales.
* High discounts reduced profitability.
* West region contributed the highest revenue.
* Office Supplies maintained consistent profits.
* Customer segmentation identified different purchasing behaviors.
