# Data Folder

## Overview

This folder contains the datasets used for Task 1 of the ApexPlanet Data Analytics Internship project.

---

## Files Included

### 1. SampleSuperstore.csv

Original dataset containing retail sales transaction records.

### 2. SampleSuperstore_Cleaned.csv

Cleaned dataset generated after performing data quality checks, duplicate removal, data type corrections, and outlier analysis.

---

## Dataset Description

The Sample Superstore dataset contains retail sales transaction data, including:

* Orders
* Customers
* Products
* Categories
* Sales
* Quantity
* Discounts
* Profit
* Regions
* States

This dataset is commonly used for practicing data analysis, data cleaning, visualization, and business intelligence techniques.

---

## Project Activities Performed

The dataset was used for:

* Data Loading using Pandas
* Dataset Exploration and Inspection
* Data Quality Assessment
* Missing Value Analysis
* Duplicate Record Detection
* Data Type Conversion
* Outlier Detection using the IQR Method
* Data Cleaning and Preprocessing
* Exploratory Data Analysis (EDA)
* Sales and Profit Analysis
* Correlation Analysis
* Trend Analysis
* Data Visualization using Matplotlib and Seaborn
* Business Insight Generation
