# Data Folder

## Overview
This folder contains the dataset used for the ApexPlanet Data Analytics Internship project.

## Dataset
- SampleSuperstore.csv

## Dataset Description
The Sample Superstore dataset contains sales transaction records of a retail store. It includes information about customers, products, orders, sales, discounts, quantities, and profits.

## Purpose
This dataset is used for:

- Data Loading using Pandas
- Data Exploration and Inspection
- Data Cleaning and Validation
- Exploratory Data Analysis (EDA)
- Sales and Profit Analysis
- Data Visualization using Matplotlib and Seaborn

## Key Columns
- Order Date
- Customer Name
- Category
- Sub-Category
- Sales
- Quantity
- Discount
- Profit
- Region
- State

## Internship Task
This dataset is used to complete Day 1 and Day 2 tasks of the ApexPlanet Data Analytics Internship.
